## Concepts Learned
### What is VirtualBox?

Oracle VirtualBox is an pen-source virtualisation software that allows multiple operating systems to run on a single physical computer. It provides a safe environment to learn, experiment, and practise without affecting the host operating system.

### What is Kali Linux?

Kali Linux is a Debian-based Linux distribution designed for penetration testing, digital forensics, vulnerability assessment, and cybersecurity research. It includes hundreds of security tools that are commonly used by cybersecurity professionals.

## Hands On Work

I started by downloading Oracle VirtualBox, which is an open-source virtualization software.
VirtualBox allows me to run multiple operating systems (virtual machines) on my computer without affecting 
my main operating system.
Using VirtualBox, I can create and run virtual machines such as Kali Linux, Ubuntu, and Windows.

I chose Kali Linux because it is mainly used for penetration testing and digital forensics. 
I downloaded the Kali Linux ISO image and attached it to a new VirtualBox virtual machine to install the operating system. 
I then started the virtual machine and completed the installation.


The first command I ran in the Kali terminal was sudo apt update.
It refreshes Kali's list of available software and updates.

I then ran sudo apt full-upgrade -y. This command downloads and installs the latest versions of packages, including bug fixes and security patches.

Then I was able to learn the basic commands which included:
- pwd (print working directory)
- ls (list)
- ls -la (list hidden files)
- mkdir (make directory)
- cd (change directory)
- touch (create file)
- nano (use Nano text editor)
- cat (display the contents of the file)
